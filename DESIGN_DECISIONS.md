# Design Decision Log

Use this file to record important design choices made while developing the
clinic appointment system. Add an entry when a decision affects the structure,
behavior, or future development of the project.

For each entry, briefly describe:

- **Decision:** What did you choose?
- **Reasoning:** Why did you choose this approach?
- **Alternatives:** What other options did you consider, and why not use them?
- **Impact:** Which parts of the system are affected?
- **References:** Which files or tests show the decision?
